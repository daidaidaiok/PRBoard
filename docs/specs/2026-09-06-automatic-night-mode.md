# PRboard 自动夜间模式设计

## 目标

让 PRboard 根据浏览器本地时间自动切换深浅主题，不增加手动切换按钮；页面长时间打开时也能在时间边界自动更新。

## 现状与搜索结论

- `src/app/globals.css` 已定义完整的 `.dark` CSS 变量和 Tailwind `dark:` 变体，可直接复用。
- `next-themes` 已在依赖中，但当前没有主题切换入口；直接引入系统主题无法表达固定时段策略。
- 因此采用 **Extend/Compose**：复用现有 `.dark` 主题变量，新增轻量客户端定时器与首屏初始化脚本，不添加按钮或持久化用户偏好。

## 方案

1. **固定时段（推荐）**：18:00（含）至次日 06:00（不含）启用深色；客户端每分钟检查一次。优点是行为确定、无需权限和外部 API。
2. **跟随系统主题**：使用 `prefers-color-scheme`。实现简单，但不是按时间定时，无法满足需求。
3. **日出日落服务**：按地理位置计算。需要位置权限或服务依赖，复杂度和隐私成本更高，不采用。

## 实现细节

- `src/lib/theme.ts` 集中定义时间边界、判断函数和 DOM 应用函数。
- `src/components/automatic-theme.tsx` 在客户端挂载后立即应用主题，并每 60 秒重新检查；卸载时清理定时器。
- 根布局使用 `beforeInteractive` 脚本在 React hydration 前设置 `.dark`，避免首屏闪白；`suppressHydrationWarning` 允许客户端主题 class 与服务端初始 HTML 不同。
- 同步设置 `color-scheme` 和 `meta[name="theme-color"]`，让原生控件与浏览器/PWA 工具栏配色一致。

## 验收标准

- [x] 18:00 和 05:59 为深色，06:00 和 17:59 为浅色。
- [x] 不出现主题切换按钮。
- [x] 页面跨越时间边界无需刷新即可切换。
- [x] lint、类型检查、测试通过。
